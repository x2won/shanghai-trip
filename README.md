# 체험학습 안내 앱 — 연변한국국제학교 상하이 체험학습

흩어졌다가 **정시에 다시 모이는 것**을 돕는 웹앱입니다. 중국에서 구글 서비스가 차단되는 환경을 전제로,
**서버 없이 인터넷이 끊겨도 동작하도록** 만들었습니다.

> 기획 배경과 설계 판단은 [PLAN.md](PLAN.md)에 정리되어 있습니다.

## 실행

```bash
python -m http.server 5500
```

브라우저에서 `http://localhost:5500` 접속.

## 화면

| 탭 | 내용 |
|---|---|
| **집결** | 집결까지 카운트다운, **"지금 출발하세요"** 역산 알림, 거리·방향 화살표, 지도(내 위치 + 집결지), 내 위치 보내기 |
| **일정** | 일차별 타임라인. 현재 진행 중인 일정 강조, 장소의 중국어 이름 표시 |
| **장소** | 장소 목록과 현재 거리. 누르면 **중국어 주소 카드**(택시 기사에게 보여주는 용도), 지도 미리 받기 |
| **비상** | 미아 대응 절차, 연락처, 중국 긴급번호, 중국어 회화 카드 |
| **교사** | 집결 링크·공지 링크 생성, 인원 점검, 일정·연락처·장소 편집, 계획표 인쇄 (헤더 오른쪽 버튼 → 코드 입력) |

## 계정 (역할)

| 역할 | 들어가는 법 | 할 수 있는 것 |
|---|---|---|
| **학생** | 그냥 접속 | 집결·일정·장소·비상 화면 보기, 내 위치 보내기 |
| **교사** | 코드 입력 | 위 + 집결 지정, 공지 보내기, 인원 점검, **일정·연락처 편집**, 계획표 인쇄 |
| **관리자** | 코드 입력 | 위 + **장소·좌표 편집**, 데이터 내보내기/불러오기/초기화 |

코드는 [data/trip.json](data/trip.json)의 `access`에 있습니다. **출발 전에 반드시 바꾸세요.**
```json
"access": { "teacherCode": "2026", "adminCode": "9999" }
```

> ⚠️ 서버가 없는 앱이라 코드가 앱 파일 안에 들어 있습니다. 마음먹고 찾으면 볼 수 있으므로
> 이건 보안이 아니라 **학생이 실수로 편집 화면에 들어가는 것을 막는 장치**입니다.
> 진짜 잠금이 필요하면 서버가 있어야 합니다.

교사가 고친 내용은 **그 기기에만** 저장됩니다. 모두에게 반영하려면
관리자 화면의 **데이터 관리 → 내보내기**로 복사해서 `data/trip.json`에 붙여넣고 다시 배포하세요.

## 핵심 동작 두 가지

**1. 출발 시각 역산**
집결 시각에서 *내 위치→집결지 도보 시간*과 여유 5분을 빼서 각자에게 맞는 출발 시각을 계산합니다.
상태가 `여유 있습니다 → N분 뒤 출발 → 지금 출발하세요 → 지각`으로 자동 전환되고, 전환될 때 알림이 울립니다.
도보 속도는 인파를 감안해 시속 3km로 잡았습니다 (`js/rally.js`의 `WALK_SPEED`).

**2. 링크로 주고받기 (서버 없음)**
- 교사 → 학생: **집결 링크** (장소·시각) / **공지 링크** (예: "예원 도착. 12시까지 자유 활동")
  위챗 단체방에 붙여넣으면, 학생이 누르는 순간 앱에 반영되고 알림이 울립니다.
- 학생 → 교사: **내 위치 보내기** → 위치가 담긴 링크 → 교사가 누르면 지도에 표시

내용이 전부 링크 안에 들어 있어 서버가 필요 없습니다.

**알림은 세 가지 상황에 울립니다** — 출발할 시각, 다음 일정 10분 전, 선생님 공지를 받았을 때.

## 지도 설정 — [js/config.js](js/config.js)

기본은 **오픈스트리트맵**입니다. 키가 필요 없고 중국에서도 접속되며, 미리 받아두면 오프라인에서도 보입니다.

**바이두 지도로 바꾸려면** `BAIDU_AK`에 키를 넣으면 자동으로 전환됩니다.
키 발급은 [百度地图开放平台](https://lbsyun.baidu.com)에서 "브라우저단 JavaScript API"로 신청합니다 (중국 계정 필요).

> ⚠️ 바이두로 바꾸면 **지도를 미리 받아두는 기능은 쓸 수 없습니다.** 바이두 지도는 항상 인터넷이 필요합니다.
> 자유 활동 중 통신이 끊길 가능성을 생각하면, 오프라인이 되는 기본 지도를 권합니다.

**중국 좌표계 처리**는 [js/coords.js](js/coords.js)에 들어 있습니다. 휴대폰 GPS(WGS-84)를 중국 지도 좌표(GCJ-02 → BD-09)로
변환하지 않으면 실제 위치에서 300~500m 어긋나 표시되는데, 바이두를 쓸 때 이 변환이 자동으로 적용됩니다.

## 일정·장소 수정

[data/trip.json](data/trip.json) 하나만 고치면 앱 전체에 반영됩니다.
현재 일정은 **예시**이며, 장소 좌표도 대략값이라 확정 후 수정이 필요합니다.
연락처(`contacts`)의 전화번호는 비어 있으니 출발 전에 채워야 합니다.

## 파일 구조

```
index.html            화면 구조
css/style.css         디자인 시스템 (다크 모드 포함)
js/config.js          지도 키·도보 속도 등 설정  ← 자주 건드릴 파일
js/coords.js          중국 좌표계 변환 (WGS-84 → GCJ-02 → BD-09)
js/geo.js             거리·방위각 계산
js/rally.js           집결 로직, 링크 인코딩, 출발 시각 역산
js/trip.js            여행 데이터 로드·저장·내보내기
js/auth.js            역할 구분 (학생/교사/관리자)
js/editor.js          편집 화면, 계획표 인쇄
js/mapview.js         지도(바이두/일반), 오프라인 타일 미리받기
js/app.js             화면 연결
data/trip.json        일정·장소·연락처·회화  ← 여기만 고치면 됨
vendor/leaflet.*      지도 라이브러리 (CDN 차단 대비해 프로젝트에 포함)
service-worker.js     오프라인 저장
```
